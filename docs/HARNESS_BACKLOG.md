# Harness 待办

当 Agent 发现缺失的 Harness 能力但不应立即改变操作模型时，使用本文件。

## 模板

```md
## 缺失的 Harness 能力

### 标题

简短名称。

### 发现于

暴露缺口的任务或 story。

### 当前痛点

何处困难、重复、模糊或不安全？

### 建议改进

应添加或改变什么？

### 风险

Tiny、normal 或 high-risk。

CLI 取值：`--risk tiny`、`--risk normal` 或 `--risk high-risk`。

### Status

proposed | accepted | implemented | rejected
```

## 条目

尚无 backlog 条目。
