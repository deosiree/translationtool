# 离线安装

安装包暂时存入项目`根目录/Cache`下

下载安装包执行以下命令

## Linux

### tree-sitter和tree-sitter-cpp

```bash 
pip3 install tree_sitter_cpp-0.23.4-cp39-abi3-manylinux_2_17_x86_64.manylinux2014_x86_64.whl
pip3 install tree_sitter-0.24.0-cp311-cp311-manylinux_2_17_x86_64.manylinux2014_x86_64.whl
```


## Window

### tree-sitter和tree-sitter-cpp

```bash 
pip3 install tree_sitter_cpp-0.23.4-cp39-abi3-win_amd64.whl
pip3 install tree_sitter-0.24.0-cp313-cp313-win_amd64.whl
```
