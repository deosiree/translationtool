# 快速开始：测试框架安装步骤

## 🚀 第一步：安装依赖（5分钟）

打开终端（PowerShell 或 CMD），在项目根目录执行：

```bash
npm install -D vitest @vue/test-utils jsdom @vitest/ui @vitest/coverage-v8
```

**等待安装完成**（可能需要 1-2 分钟）

---

## 📝 第二步：创建配置文件（2分钟）

### 2.1 创建 `vitest.config.js`

在项目根目录创建文件 `vitest.config.js`，复制以下内容：

```javascript
import { defineConfig } from 'vitest/config'
import vue from '@vitejs/plugin-vue'
import { resolve } from 'path'

export default defineConfig({
  plugins: [vue()],
  test: {
    environment: 'jsdom',
    globals: true,
    include: ['tests/**/*.{test,spec}.{js,mjs,cjs,ts,mts,cts,jsx,tsx}'],
    coverage: {
      provider: 'v8',
      reporter: ['text', 'json', 'html'],
      exclude: [
        'node_modules/',
        'tests/',
        '*.config.js',
        'src/main.js',
        'src/router/**',
        'src/store/**',
      ]
    }
  },
  resolve: {
    alias: {
      '@': resolve(__dirname, './src')
    }
  }
})
```

**注意**：如果项目中没有 `@vitejs/plugin-vue`，需要先安装：

```bash
npm install -D @vitejs/plugin-vue
```

## 📦 第三步：更新 package.json（1分钟）

打开 `package.json`，在 `"scripts"` 部分添加以下命令：

```json
{
  "scripts": {
    "serve": "vue-cli-service serve",
    "build": "vue-cli-service build",
    "lint": "vue-cli-service lint",
    "test": "vitest run",
    "test:watch": "vitest",
    "test:ui": "vitest --ui",
    "test:coverage": "vitest run --coverage",
    "electron:build": "vue-cli-service electron:build",
    "electron:serve": "vue-cli-service electron:serve",
    "postinstall": "electron-builder install-app-deps",
    "postuninstall": "electron-builder install-app-deps"
  }
}
```

---

## 📁 第四步：创建测试目录（1分钟）

在项目根目录创建测试目录：

**PowerShell 命令**：
```powershell
New-Item -ItemType Directory -Force -Path tests\unit\utils
```

**或者手动创建**：
1. 在项目根目录创建 `tests` 文件夹
2. 在 `tests` 下创建 `unit` 文件夹
3. 在 `unit` 下创建 `utils` 文件夹

目录结构应该是：
```
项目根目录/
├── tests/
│   └── unit/
│       └── utils/
```

---

## ✅ 第五步：创建第一个测试文件（3分钟）

在 `tests/unit/utils/` 目录下创建 `dateUtils.test.js`：

```javascript
import { describe, it, expect } from 'vitest'
import { getCurrentFormattedTime, getCurrentStringTime } from '@/utils/commonUtils'

describe('dateUtils - 时间工具函数', () => {
  describe('getCurrentFormattedTime', () => {
    it('应该返回正确格式的时间字符串 (YYYY-MM-DD HH:mm:ss)', () => {
      const time = getCurrentFormattedTime()
      // 验证格式：YYYY-MM-DD HH:mm:ss
      expect(time).toMatch(/^\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}$/)
    })
  })

  describe('getCurrentStringTime', () => {
    it('应该返回正确格式的时间字符串 (YYYYMMDDHHmmss)', () => {
      const time = getCurrentStringTime()
      // 验证格式：YYYYMMDDHHmmss（14位数字）
      expect(time).toMatch(/^\d{14}$/)
    })
  })
})
```

## 🧪 第六步：运行第一个测试（1分钟）

在终端执行：

```bash
npm test
```

**预期输出**：
```
✓ tests/unit/utils/dateUtils.test.js (2)

Test Files  1 passed (1)
     Tests  2 passed (2)
      Time  0.5s
```

**如果看到错误**：
- 检查 `vitest.config.js` 文件是否正确创建
- 检查路径别名 `@` 是否配置正确
- 确保 `@/utils/commonUtils` 中导出了 `getCurrentFormattedTime` 和 `getCurrentStringTime`

## 🐛 常见问题解决

### 问题 1: 找不到模块 '@/utils/commonUtils'

**解决方案**：
1. 检查 `vitest.config.js` 中的路径别名配置
2. 确保 `resolve.alias['@']` 指向 `./src` 目录

### 问题 2: 提示找不到 '@vitejs/plugin-vue'

**解决方案**：
```bash
npm install -D @vitejs/plugin-vue
```

### 问题 3: 测试运行但找不到测试文件

**解决方案**：
1. 检查测试文件命名：必须是 `*.test.js` 或 `*.spec.js`
2. 检查文件位置：应该在 `tests/` 目录下
3. 检查 `vitest.config.js` 中的 `include` 配置

### 问题 4: Vue 相关错误

**解决方案**：
确保安装了 `@vue/test-utils`：
```bash
npm install -D @vue/test-utils
```
