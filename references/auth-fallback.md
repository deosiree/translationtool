# LDAP 认证与本地兜底

## 认证流程

```
登录请求 → UserLoginController → UserLoginService.login()
            ↓
  LDAPUtils.LDAP_AUTH_AD(account, password)
            ↓
  尝试连接 LDAP 服务器（ldap://10.17.196.129:389）
            ↓
      ┌────成功────┐
      │ LDAP 认证通过 │
      └────┬────────┘
           ↓
    返回 true → 登录成功
```

```
      ┌────失败（超时/网络不通）────┐
      │  catch 块捕获异常           │
      │  超时时间: 2 秒             │
      └────┬───────────────────────┘
           ↓
    检查是否是兜底账户
      ┌──────────────┐
      │ admin/       │  → 返回 true → 登录成功
      │ admin123     │
      └──────────────┘
      ┌──────────────┐
      │ 其他账户      │  → 返回 false → 登录失败 (code 208)
      └──────────────┘
```

## 本地兜底账户

| 账户 | 密码 | 说明 |
|---|---|---|
| `admin` | `admin123` | LDAP 不可用时自动生效，权限等同"管理员"角色 |

代码位置：`LDAPUtils.java` 第 47-81 行 `LDAP_AUTH_AD()` 方法。

## 为什么外网 LDAP 会超时

LDAP 服务器 `10.17.196.129:389` 在公司内网。外网无法访问该 IP，连接尝试会在 2 秒后超时，然后自动降级到本地兜底。

## 超时时间

- 原默认超时：约 42 秒（Java JNDI 默认 + TCP 超时）
- 当前设置：**2 秒**（在 `LDAPUtils.java` 中通过 `com.sun.jndi.ldap.connect.timeout=2000` 显式设置）

## 注意

- 兜底账户登录后属于"管理员"角色，部门为"通用平台部"
- 兜底账户无法修改密码
- 如需要其他兜底账户，需修改 `LDAPUtils.java` 源码后重新编译
